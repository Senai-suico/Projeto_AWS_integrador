# Projeto Integrador - Praticando com um banco de dados da AMAZON
---

# Proposta 
No desenvolvimento do Projeto Integrador, foi disponibilizado inicialmente um banco de dados contendo avaliações de usuários sobre diferentes produtos e serviços. Essas avaliações serviram como base principal para todas as etapas do projeto, permitindo a extração de informações relevantes e a realização de análises voltadas ao comportamento e à opinião dos usuários.

A primeira etapa realizada foi o tratamento dos dados. Nessa fase, os dados passaram por processos de limpeza e organização, removendo informações duplicadas, corrigindo inconsistências e tratando valores ausentes. Esse processo foi fundamental para garantir maior qualidade e confiabilidade nas análises posteriores, além de preparar a base para o processamento e interpretação dos dados.

Após o tratamento, foi desenvolvida a análise exploratória dos dados, com o objetivo de compreender melhor o conteúdo presente no banco. Foram analisados padrões, distribuições, frequência das avaliações, médias, tendências e possíveis relações entre as informações coletadas. Essa etapa permitiu identificar comportamentos relevantes dos usuários e obter uma visão geral dos dados antes da aplicação de técnicas mais avançadas.

Em seguida, foi realizada a análise de sentimento utilizando a ferramenta de Inteligência Artificial chamada LeIA. Essa ferramenta foi utilizada para interpretar automaticamente os sentimentos expressos nas avaliações dos usuários, classificando os comentários em categorias como positivos, negativos e neutros. A aplicação da IA possibilitou transformar textos subjetivos em informações quantitativas, facilitando a interpretação das opiniões presentes no banco de dados.

Com os resultados obtidos, foi possível gerar insights sobre a satisfação dos usuários, identificar pontos positivos e negativos mais recorrentes e compreender melhor a percepção geral em relação aos itens avaliados. Dessa forma, o projeto integrou etapas de tratamento de dados, análise exploratória e Inteligência Artificial para produzir informações relevantes e apoiar a tomada de decisões baseada em dados.
